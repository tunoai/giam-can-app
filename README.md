# FitLife – app giảm cân

Web app dạng ứng dụng điện thoại: AI gợi ý món ăn, gọi món từ ảnh, giáo trình chạy 5K 12 tuần, hướng dẫn máy gym, nhật ký cân nặng.

Mở trên điện thoại rồi chọn "Thêm vào màn hình chính" để dùng như app.

Ảnh minh hoạ bài tập trong `img/ex/` lấy từ [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (The Unlicense).
